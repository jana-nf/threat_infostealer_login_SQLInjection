# threat_infostealer_login_SQLInjection
Motor de correlação de eventos de segurança (estilo mini-SIEM) desenvolvido em Python para detecção avançada de ameaças. O projeto correlaciona eventos isolados de baixa severidade que, quando combinados, formam uma cadeia de ataque (kill chain) crítica, disparando alertas automatizados em tempo real via Telegram.
